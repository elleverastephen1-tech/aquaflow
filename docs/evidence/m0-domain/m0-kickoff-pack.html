D-1 Routes

Customer owns zones and routes. Reading owns route assignments. The Dev Plan's route_assignments in customer_db is treated as a defect.

D-2 Previous reading

Reading owns it. Customer only sends the initial and final readings captured at install and replace.

D-3 Meter data in Reading

Sync call in M4, then a read model from customer.* events in M7 (ADR-0007, likely reversed).

Billing check: the three mandatory totals

Residential tariff 2026-01 in integer cents. Each percentage line is rounded half-up on its own. The same maths is in billing-check.mjs.
